# CrewConnect – HR & Employee Management System

## 📌 Project Overview

CrewConnect is a web-based Human Resource Management System developed using Python and Django. It provides separate HR/Admin and Employee dashboards to simplify employee management, onboarding, and HR operations.

## ✨ Features

### HR/Admin Dashboard
- Manage employee records.
- Manage departments and designations.
- Support employee onboarding.
- Access and organize HR-related information.

### Employee Dashboard
- Dedicated employee dashboard.
- Access relevant employee information.
- Account access based on user permissions.

### Authentication
- User login and authentication.
- Separate access for HR/Admin and employees.
- Employee account setup and password creation workflow.

## ⚙️ How to Run the Project

### 1. Clone the Repository
```bash
git clone https://github.com/lavanyaM-12/crewconnect-Django.git
cd crewconnect-Django
```

### 2. Create a Virtual Environment
```bash
python -m venv venv
```

### 3. Activate the Environment (Windows)
```bash
venv\Scripts\activate
```

### 4. Install Dependencies
```bash
pip install -r requirements.txt
```

### 5. Apply Migrations
```bash
python manage.py migrate
```

### 6. Start the Server
```bash
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.

*Note: These instructions assume the project includes `manage.py` and `requirements.txt`. Database settings or environment variables may require additional configuration.*
